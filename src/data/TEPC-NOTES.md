# NASA ISS TEPC dataset — verification notes

Retrieved 2026-11-14 from NASA CDAWeb. Everything below was read directly from the
dataset's own metadata and data responses during this retrieval — nothing is inferred
or invented.

## What TEPC is

- TEPC is a radiation-measuring instrument flown on the International Space Station
  (ISS). In all of the NASA metadata retrieved, the instrument is named simply
  "TEPC" (CDF `Descriptor` = "TEPC>TEPC", `Instrument_type` = "Particles (space)").
- It measures the radiation environment **inside** the ISS. The dataset's `LOCATION`
  variable records where the instrument sits inside the station; in the window
  sampled here it was "SM P330 PORT" (Service Module).
- The measurements in this dataset are the **environmental radiation dose rates
  inside the ISS** — they are NOT personal dosimeter readings for any individual
  astronaut.
- Dataset PI: Edward Semones, NASA Space Radiation Analysis Group / Johnson Space
  Center. The CDF files were generated by SPDF from ASCII files provided by JSC
  ("Generated_by" attribute). The CDF TEXT attributes also record: "TEPC serrial
  number = 1003" and "TEPC Analysis SoftwareVersion Number = 3.1" (spellings as in
  the metadata).
- SPASE resource ID: `spase://NASA/NumericalData/ISS/TEPC/PT10S`.

## Dataset

- **ID:** `ISS_DOSANL_TEPC`
- **Full name (dataset label):** "Experiment Data, ISS TEPC (from ASCII DOS.TXT file)"
- **Data type:** DOSANL > Dose Analyzed
- **Coverage (from CDAS dataset listing):** 2010-04-29T03:27:36Z to 2018-04-11T23:19:39Z
- **Observatory / instrument:** ISS / TEPC

Fill value for the numeric variables is -1.0E31 (CDF `FILLVAL`).

## Variable chosen for the app sample

- **DOSE — "Average dose rate", units `uGy/min`** (exactly as written in the CDF
  metadata). Chosen because absorbed dose rate is the dataset's primary,
  plain-language radiation measurement and is directly chartable as a time series.
  (DOSE_EQ60 in uSv/min is also available in the same dataset if the app later
  wants dose equivalent instead.)

## Cadence

- 1 record per minute in the sampled window: consecutive Epochs are 60 s apart and
  the dataset's own `TIME_INTERVAL` variable reads 1.0 (min) — each DOSE value is
  the average dose rate over a 1-minute collection interval.

## Sample shipped in `tepc.json`

- Window requested: 2018-01-01T00:00:00Z to 2018-01-05T00:00:00Z.
- Records actually returned: 5,748, spanning 2018-01-01T00:00:23Z to
  2018-01-04T23:47:22Z (the source simply has 12 fewer 1-minute records than a
  full 4×1440 grid). No fill values were present in this window.
- **Thinning:** native cadence is 1/minute, so every 30th record was kept →
  192 points at 30-minute spacing, 2018-01-01T00:00:23Z to 2018-01-04T23:30:22Z.
  Values and timestamps are the original records, unmodified — nothing was
  averaged, interpolated, rounded or otherwise altered. Observed value range in
  the full window: 0.02 to 18.669 uGy/min (the high values are brief spikes in
  the real record).
